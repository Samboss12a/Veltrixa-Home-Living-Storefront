# Veltrixa static storefront

A responsive, 17-page HTML/CSS-only home furnishings storefront. All forms and controls are presentational; no JavaScript, PHP, payment processing, or backend is included.

## Open the site
Open `index.html` in a browser. The pages link to each other using relative paths. Shared styling is in `assets/css/style.css`.

## Pages
Home, Shop, Collections, Product detail, Cart, Checkout, Order success, Sign in, Register, Account, Orders, About, Contact, FAQs, Shipping & returns, Saved pieces, Admin dashboard.

Product and lifestyle art are CSS placeholders labeled for replacement. Replace each placeholder `<div>` with an `<img>` element and useful alt text when adding your own images. The Google Fonts import falls back to system fonts if unavailable.

# Veltrixa — Home & Living Storefront

Veltrixa is a responsive, static e-commerce website concept for a home furnishings and decor brand. It includes 17 linked pages, built with HTML and CSS, with sample product details and replaceable image placeholders.

## Pages

- Home
- Shop
- Collections
- Product details
- Shopping bag
- Checkout
- Order confirmation
- Sign in and registration
- Account overview and order history
- About
- Contact
- FAQs
- Shipping and returns
- Saved pieces
- Admin dashboard

## Built with

- HTML5
- CSS3

## Getting started

Download or clone the project, then open `index.html` in a browser. The pages use relative links and share styling from `assets/css/style.css`.

## Customization

Replace the labeled image placeholders with your own images and update the sample products, prices, and text. Forms and buttons are for presentation only; the site does not include JavaScript, payment processing, or backend functionality.
